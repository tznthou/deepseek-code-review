# 實測紀錄

這個 kit 對自己做過的量測都列在這裡：問了什麼、怎麼量、結果是什麼。

- 有頁面的，數字以頁面為準。已經寫在 README 或 CHANGELOG 的，這裡只寫一句結論、連過去，數字不重抄。
- 模型輸出、標記單、腳本這些原始資料放在不進 repo 的私有目錄，公開的是整理過的結論。牽涉 private repo 的只寫匿名摘要。
- 每做完一組實驗，就在這裡加一列；寫好頁面的連過去。

## 還沒整理進來的

kit 本身有沒有照說的運作——Actions 政策、強制釘 SHA、CodeQL 告警分流、在外部 repo 從頭裝一次——也做過一批驗證。結果大多已經寫在 [CHANGELOG](../CHANGELOG.md) 對應的版本裡，之後整理成同樣的格式。
